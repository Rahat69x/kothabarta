# গল্পঘর (Golpoghor)

বাংলা গল্প, প্রবন্ধ ও অভিজ্ঞতার উন্মুক্ত প্ল্যাটফর্ম।

## Features

- **পড়ুন ও অন্বেষণ করুন**: বিভিন্ন ক্যাটাগরি, ধারা (Genre) ও স্ট্যাটাস অনুযায়ী গল্প এবং প্রবন্ধ ব্রাউজ করুন।
- **ধারাবাহিক প্রকাশনা**: বহু-খণ্ডের গল্প বা ধারাবাহিক প্রকাশ করুন।
- **লেখক প্রোফাইল**: লেখক অ্যাকাউন্ট ও ব্যক্তিগত লাইব্রেরি।
- **দ্বিভাষিক সমর্থন**: বাংলা এবং ইংরেজি ইন্টারফেস।
- **ডার্ক ও লাইট মোড**: আধুনিক থিম সাপোর্ট।

## Development

Prerequisites: Node.js (v18+) and npm / bun.

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase
- **Language**: TypeScript
